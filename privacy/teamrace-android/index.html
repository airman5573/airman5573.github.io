팀레이스(Teamrace) Android 앱 개인정보처리방침

시행일 및 최종 업데이트: 2026년 7월 26일

본 개인정보처리방침은 팀레이스 운영자(airman5573)가 제공하는 팀레이스(영문 표기 Teamrace) Android 앱(패키지명: kr.ai.asol.teamrace, 이하 “앱”)이 행사·워크숍·수업의 실시간 팀 단어 레이스를 제공하기 위해 어떤 정보를 처리하는지 설명합니다.

보이스 모드의 음성 인식은 Android 기기에 설치된 기본 음성 인식 서비스가 수행합니다. 대부분의 기기에서는 Google 앱이 이 기능을 제공하며, 기기 설정과 언어팩 설치 상태에 따라 해당 제공자의 서버에서 음성이 처리될 수 있습니다. Teamrace 서버로는 마이크 음성과 전체 인식 문장을 전송하지 않으며, 화면의 단어와 일치한 경우 그 정답 키만 채점을 위해 전송합니다. 앱은 광고 SDK, 광고 식별자 또는 제3자 분석·추적 기능을 사용하지 않습니다.

iOS 앱의 개인정보처리방침은 별도 페이지(https://airman5573.github.io/privacy/teamrace/)에 있습니다. 음성 인식 처리 방식이 플랫폼마다 다르므로 Android 앱에는 본 방침이 적용됩니다.

1. 처리하는 정보

구분처리 항목처리 목적
팀 인증 및 세션 정보 사용자가 입력한 팀 입장 코드, 서버가 부여한 팀 ID·역할, 로그인 상태와 세션 쿠키 팀 인증, 로그인 상태 유지, 해당 팀의 경기 연결
게임플레이 정보 맞힌 정답 키, 정답에 적용되는 진행 배수, 개인·팀 점수, 경기 상태, 순위 및 진행 결과 실시간 채점, 팀 점수 동기화, 경기 진행과 결과 표시
서버 콘텐츠 서버가 제공하는 게임 아이템 ID, 표시 단어, 이미지 URL 및 정답 키 게임 카드 표시와 정답 판정
기기 내 설정 앱이 보관하는 Teamrace 서버 주소 설정값, Teamrace 세션 쿠키 서버 연결과 앱 재실행 시 로그인 세션 복구
통신 및 운영 정보 IP 주소, 접속 시각, 네트워크 요청·응답 및 오류 정보 등 서버 운영 과정에서 생성될 수 있는 기록 서비스 제공, 보안, 부정 이용 방지, 장애 진단 및 품질 유지

팀 입장 코드는 인증을 위해 서버로 전송됩니다. 앱은 입장 코드를 기기에 저장하지 않으며 분석 SDK에도 남기지 않습니다. 다만 로그인 성공 후 서버가 발급한 세션 쿠키를 기기 내부 저장소에 보관하여 세션을 복구합니다. 팀 입장 코드는 개인 이름·이메일·전화번호를 요구하는 개인 계정이 아니라 행사 운영자가 팀 단위로 제공하는 공유 인증 정보입니다.

2. 앱이 요청하는 권한

  • 마이크(RECORD_AUDIO): 보이스 모드에서 사용자가 말한 단어를 인식하기 위해 사용합니다.
  • 인터넷·네트워크 상태(INTERNET, ACCESS_NETWORK_STATE): 경기 서버 연결과 연결 상태 확인에 사용합니다.
  • 진동(VIBRATE): 정답 처리 시 촉각 피드백에 사용합니다.

앱은 위치, 연락처, 사진·미디어, 파일, 캘린더, 전화 관련 권한을 요청하지 않습니다.

3. 마이크와 음성 인식

  • 인식 방식: 앱은 Android 표준 SpeechRecognizer API를 사용해 기기에 설치된 기본 음성 인식 서비스에 인식을 요청합니다. 대부분의 기기에서는 Google 앱이 이 서비스를 제공합니다.
  • 처리 위치: 인식이 기기 내부에서 이루어질지, 제공자의 서버에서 이루어질지는 기기 제조사 설정과 한국어 언어팩 설치 상태에 따라 달라집니다. 이 처리에는 해당 제공자의 개인정보처리방침이 적용됩니다.
  • 서버 전송 없음: 원본 마이크 음성과 전체 인식 문장은 Teamrace 서버로 보내지 않습니다. 화면의 단어와 일치한 경우 그 정답 키만 채점을 위해 보냅니다.
  • 저장 없음: 앱은 음성을 기기에 저장하지 않으며 녹음 파일을 만들지 않습니다.

사용자는 권한을 허용하지 않거나 Android 설정에서 언제든 철회할 수 있습니다. 권한을 허용하지 않으면 보이스 모드는 사용할 수 없지만, 운영 중인 경기가 타이핑 모드를 제공하는 경우 마이크 없이 참여할 수 있습니다.

4. 정보의 이용 목적

  • 팀 입장 코드 인증과 로그인 세션 유지
  • 실시간 경기 연결, 정답 판정, 개인·팀 점수 및 순위 계산
  • 게임 단어와 이미지 표시
  • 경기 상태와 결과의 실시간 동기화
  • 서비스 보안, 부정 이용 방지, 장애 분석 및 안정성 유지
  • 사용자 문의와 권리 행사 요청 대응

5. 정보의 보관 및 삭제

팀 인증·경기·점수 정보와 서버 로그는 경기 운영, 결과 확인, 보안, 장애 및 분쟁 대응에 필요한 기간 동안 보관한 뒤 목적이 달성되면 삭제하거나 식별하기 어려운 형태로 처리합니다. 법령상 보존 의무가 있는 정보는 해당 법정 기간 동안 보관할 수 있습니다.

사용자가 앱에서 로그아웃하면 기기에 저장된 Teamrace 세션 쿠키가 삭제됩니다. 앱을 삭제하면 앱 저장소의 설정과 세션 정보도 기기에서 삭제됩니다. 앱 삭제 또는 로그아웃은 서버에 이미 저장된 경기 기록을 자동으로 삭제하지 않으며, 서버 기록의 열람·삭제 요청은 아래 문의처로 보낼 수 있습니다.

6. 외부 서비스와 정보 공유

앱은 기능 제공을 위해 운영 서버 https://teamrace.asol.ai.kr와 HTTPS 및 WSS로 통신합니다. 보이스 모드에서는 위 3항에 설명한 대로 Android 기본 음성 인식 서비스에 음성이 전달됩니다. 개인정보처리방침 페이지는 GitHub Pages에서 제공되므로 이 페이지 접속 시 GitHub의 서버 로그 및 쿠키 정책이 적용될 수 있습니다.

운영자는 법령상 요구되거나 사용자의 동의가 있는 경우를 제외하고 처리 정보를 판매하지 않으며, 광고 네트워크 또는 제3자 추적 사업자와 공유하지 않습니다. 서비스 제공을 위해 처리 위탁이나 외부 사업자가 추가되는 경우, 해당 사업자에게 본 방침 및 적용 법령과 동등한 수준의 보호를 요구하고 이 방침을 갱신합니다.

7. 추적 및 광고

  • 앱은 광고 ID(AAID) 등 광고 식별자를 사용하지 않습니다.
  • 앱에는 제3자 광고 SDK, 분석 SDK, 크래시 리포팅 SDK가 포함되어 있지 않습니다.
  • 앱의 정보를 다른 회사의 앱·웹사이트 활동과 결합하여 광고 프로필을 만들지 않습니다.
  • 앱에는 인앱 결제, 현금성 경품, 베팅·도박 요소가 없습니다.

8. 사용자의 선택과 권리

  • 사용자는 Android 설정에서 마이크 권한을 언제든 변경할 수 있습니다.
  • 사용자는 앱에서 로그아웃하여 Teamrace 세션 쿠키를 삭제할 수 있습니다.
  • 사용자는 개인정보 또는 팀 경기 정보의 열람, 정정, 삭제, 처리 제한을 요청할 수 있습니다.
  • 공유 팀 입장 코드는 다른 사람에게 노출되지 않도록 행사 운영자의 안내에 따라 관리해야 합니다.

9. 아동의 개인정보

앱은 일반 대중을 위한 소셜 네트워크가 아니라 행사·워크숍·수업에서 팀 단위로 사용하는 게임 도구입니다. 앱은 개인 이름, 이메일 또는 전화번호를 직접 요구하지 않습니다. 만 14세 미만 사용자가 참여하는 행사의 운영자는 적용 법령과 현장 운영 정책에 따라 보호자 동의 등 필요한 절차를 마련해야 합니다. 운영자는 권한 없이 아동의 개인정보가 제공된 사실을 알게 되면 관련 법령에 따라 필요한 조치를 취합니다.

10. 보안

운영자는 HTTPS/WSS 암호화 통신, 세션 접근 제어와 운영 관리 절차 등 합리적인 보호조치를 사용합니다. 다만 인터넷 통신과 전자적 저장 방식의 특성상 모든 위험을 완전히 제거할 수는 없습니다.

11. 방침 변경

앱 기능, 서버 운영 방식 또는 관련 법령이 변경되면 본 방침을 수정할 수 있습니다. 변경된 시행일과 최종 업데이트 날짜는 이 페이지에 표시하며, 중요한 변경은 필요한 경우 앱 또는 서비스 운영 채널을 통해 추가로 알립니다.
