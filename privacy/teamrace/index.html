Teamrace iOS 앱 개인정보처리방침

시행일 및 최종 업데이트: 2026년 7월 24일

본 개인정보처리방침은 Teamrace 운영자(airman5573)가 제공하는 Teamrace iOS 앱(Bundle ID: kr.ai.asol.teamrace.animationlab, 이하 “앱”)이 행사·워크숍·수업의 실시간 팀 단어 레이스를 제공하기 위해 어떤 정보를 처리하는지 설명합니다.

보이스 모드의 마이크 음성과 전체 음성 인식 문장은 지원 기기에서 Apple의 온디바이스 음성 인식으로 처리되며 Teamrace 서버로 전송되지 않습니다. 서버에는 경기 채점을 위해 맞힌 정답 키만 전송됩니다. 앱은 광고 SDK, 광고 식별자 또는 제3자 광고 추적 기능을 사용하지 않습니다.

1. 처리하는 정보

구분처리 항목처리 목적
팀 인증 및 세션 정보 사용자가 입력한 팀 입장 코드, 서버가 부여한 팀 ID·역할, 로그인 상태와 세션 쿠키 팀 인증, 로그인 상태 유지, 해당 팀의 경기 연결
게임플레이 정보 맞힌 정답 키, 정답에 적용되는 진행 배수, 개인·팀 점수, 경기 상태, 순위 및 진행 결과 실시간 채점, 팀 점수 동기화, 경기 진행과 결과 표시
서버 콘텐츠 서버가 제공하는 게임 아이템 ID, 표시 단어, 이미지 URL 및 정답 키 게임 카드 표시와 정답 판정
기기 내 설정 사용자가 설정한 Teamrace 서버 주소, Teamrace 세션 쿠키 서버 연결 설정과 앱 재실행 시 로그인 세션 복구
통신 및 운영 정보 IP 주소, 접속 시각, 네트워크 요청·응답 및 오류 정보 등 서버 운영 과정에서 생성될 수 있는 기록 서비스 제공, 보안, 부정 이용 방지, 장애 진단 및 품질 유지

팀 입장 코드는 인증을 위해 서버로 전송됩니다. 앱은 입장 코드를 별도의 앱 데이터베이스나 분석 SDK에 저장하지 않지만, 로그인 성공 후 서버가 발급한 tr_session 쿠키를 기기에 보관하여 세션을 복구할 수 있습니다. 팀 입장 코드는 개인 이름·이메일·전화번호를 직접 요구하는 개인 계정이 아니라 행사 운영자가 팀 단위로 제공하는 공유 인증 정보입니다.

2. 마이크와 음성 인식

  • 마이크 권한: 보이스 모드에서 사용자가 말한 단어를 인식하기 위해 사용합니다.
  • 음성 인식 권한: 한국어 단어를 Apple의 음성 인식 프레임워크로 판정하기 위해 사용합니다.
  • 온디바이스 처리: 앱은 requiresOnDeviceRecognition을 사용하며, 지원되는 기기에서 음성 인식을 기기 안에서 수행합니다.
  • 서버 전송 없음: 원본 마이크 음성과 전체 인식 문장은 Teamrace 서버로 보내지 않습니다. 화면의 단어와 일치한 경우 그 정답 키만 채점을 위해 보냅니다.

사용자는 권한을 허용하지 않거나 iOS 설정에서 언제든 철회할 수 있습니다. 권한을 허용하지 않으면 보이스 모드는 사용할 수 없지만, 운영 중인 경기가 타이핑 모드를 제공하는 경우 마이크 없이 참여할 수 있습니다.

3. 정보의 이용 목적

  • 팀 입장 코드 인증과 로그인 세션 유지
  • 실시간 경기 연결, 정답 판정, 개인·팀 점수 및 순위 계산
  • 게임 단어와 이미지 표시
  • 경기 상태와 결과의 실시간 동기화
  • 서비스 보안, 부정 이용 방지, 장애 분석 및 안정성 유지
  • 사용자 문의와 권리 행사 요청 대응

4. 정보의 보관 및 삭제

팀 인증·경기·점수 정보와 서버 로그는 경기 운영, 결과 확인, 보안, 장애 및 분쟁 대응에 필요한 기간 동안 보관한 뒤 목적이 달성되면 삭제하거나 식별하기 어려운 형태로 처리합니다. 법령상 보존 의무가 있는 정보는 해당 법정 기간 동안 보관할 수 있습니다.

사용자가 앱에서 로그아웃하면 기기에 저장된 Teamrace 세션 쿠키가 삭제됩니다. 앱을 삭제하면 앱의 서버 주소 설정과 앱 저장소의 세션 정보도 기기에서 삭제됩니다. 앱 삭제 또는 로그아웃은 서버에 이미 저장된 경기 기록을 자동으로 삭제하지 않으며, 서버 기록의 열람·삭제 요청은 아래 문의처로 보낼 수 있습니다.

5. 외부 서비스와 정보 공유

앱은 기능 제공을 위해 운영 서버 https://teamrace.asol.ai.kr와 HTTPS 및 WSS로 통신하며, Apple의 iOS, URLSession, Speech 및 AVFoundation 프레임워크를 사용합니다. 개인정보처리방침 페이지는 GitHub Pages에서 제공되므로 이 페이지 접속 시 GitHub의 서버 로그 및 쿠키 정책이 적용될 수 있습니다.

운영자는 법령상 요구되거나 사용자의 동의가 있는 경우를 제외하고 처리 정보를 판매하지 않으며, 광고 네트워크 또는 제3자 추적 사업자와 공유하지 않습니다. 서비스 제공을 위해 처리 위탁이나 외부 사업자가 추가되는 경우, 해당 사업자에게 본 방침 및 적용 법령과 동등한 수준의 보호를 요구하고 이 방침을 갱신합니다.

6. 추적 및 광고

  • 앱은 AppTrackingTransparency에 따른 사용자 추적을 수행하지 않습니다.
  • 앱은 IDFA 등 광고 식별자를 사용하지 않습니다.
  • 앱에는 제3자 광고 SDK 또는 분석 SDK가 포함되어 있지 않습니다.
  • 앱의 정보를 다른 회사의 앱·웹사이트 활동과 결합하여 광고 프로필을 만들지 않습니다.

7. 사용자의 선택과 권리

  • 사용자는 iOS 설정에서 마이크와 음성 인식 권한을 변경할 수 있습니다.
  • 사용자는 앱에서 로그아웃하여 Teamrace 세션 쿠키를 삭제할 수 있습니다.
  • 사용자는 개인정보 또는 팀 경기 정보의 열람, 정정, 삭제, 처리 제한을 요청할 수 있습니다.
  • 공유 팀 입장 코드는 다른 사람에게 노출되지 않도록 행사 운영자의 안내에 따라 관리해야 합니다.

8. 아동의 개인정보

앱은 일반 대중을 위한 소셜 네트워크가 아니라 행사·워크숍·수업에서 팀 단위로 사용하는 게임 도구입니다. 앱은 개인 이름, 이메일 또는 전화번호를 직접 요구하지 않습니다. 만 14세 미만 사용자가 참여하는 행사의 운영자는 적용 법령과 현장 운영 정책에 따라 보호자 동의 등 필요한 절차를 마련해야 합니다. 운영자는 권한 없이 아동의 개인정보가 제공된 사실을 알게 되면 관련 법령에 따라 필요한 조치를 취합니다.

9. 보안

운영자는 HTTPS/WSS 암호화 통신, 세션 접근 제어와 운영 관리 절차 등 합리적인 보호조치를 사용합니다. 다만 인터넷 통신과 전자적 저장 방식의 특성상 모든 위험을 완전히 제거할 수는 없습니다.

10. 방침 변경

앱 기능, 서버 운영 방식 또는 관련 법령이 변경되면 본 방침을 수정할 수 있습니다. 변경된 시행일과 최종 업데이트 날짜는 이 페이지에 표시하며, 중요한 변경은 필요한 경우 앱 또는 서비스 운영 채널을 통해 추가로 알립니다.
